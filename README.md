# 生康足球队纪念站

武汉纺织大学生物医学工程与健康学院足球队的记录网站。这里保存建队、训练、比赛、队员与球队生活中的真实照片和资料。

> **维护规则只看一份文件：[`rule.md`](rule.md)。** 数据怎么录、文案怎么写、怎么发布、有哪些坑，全在里面。
> 这份 README 只做项目介绍与目录导览。

## 这支球队

生康足球队于 2025 年开始组建。最初因为不能再以联院形式参赛，学院人数又少，队伍一度连能否成形都不确定。后来有人持续拉人报名、订队服，队员们一起把人数凑齐；第一次排阵容时，大家在食堂讨论出了最初的 4-2-3-1 站位。

球队的第一段正式比赛是十一人制纺大杯。首战在雨中以 2:4 对阵管理学院，虽然没有赢球，但球队没有被打散，打出了自己的风采。之后在首届八人制新生杯中，球队最终取得第七名。

材料学院一直是生康足球队的兄弟学院。从球队还没有成形，到成立初期的场边指导和加油，材料学院的学长给过球队很多帮助。这份关系也会继续传给之后加入的新队员。

## 数据是怎么流转的

```
data/比赛录入.xlsx ──python tools/import_matches.py──┐
                                                     ▼
                              data/team-records.json（唯一手写数据源）
                                                     │
                                  node tools/build_team_data.mjs
                                                     ▼
                      js/team-data.js + data/player-stats.json（生成，禁止手改）
                                                     ▼
                                              网站页面
```

- **录比赛**：在 `data/比赛录入.xlsx` 填表，然后 `python tools/import_matches.py`（详见 [rule.md](rule.md) 第 4.6 节）。
- **改球员资料 / 首发**：只改 `data/team-records.json`，再跑构建（第 5 章）。
- **赛后采集**：按 [`docs/比赛数据收集清单.md`](docs/比赛数据收集清单.md) 的 20 个问题问清再填表。
- **发公告**：固定格式与线上链接要求见 [rule.md](rule.md) 第 8.3 节。

`data/生康足球队数据源.xlsx` 是 2026-10-16 迁移前的历史存档，**只读**，不要再用它改球员或赛程。

## 网站内容

- **首页轮播**：球队合照、建队故事与材料学院的兄弟情谊。
- **新赛季招新**：首页导航和首屏入口可直达招新区，扫码加入 QQ 群；群号为 `913800697`。
- **赛事档案**：按年份和杯赛索引浏览比赛。当前默认展示 `2026 · 十一人制纺大杯`，点击比分卡片查看详情。
- **沉浸式首发阵容**：固定 4-3-3 首发。桌面端滚动依次聚焦前锋、中场、后卫和门将；手机端左右滑动球场或绿色信息卡切换阵线。
- **自由战术板**：六种阵型，可拖拽换人，只存在浏览器本地。
- **队员档案**：展示真实球员资料、头像、位置、评分、踢球风格和队友评价。
- **影像墙**：雨天训练、比赛围圈、球队合照、毕业与场外日常；支持点赞和照片详情查看。
- **队史节点**：记录建队、十一人制首战、首届新生杯第七名与材料学院的帮助。

## 赛事归档

学校每学年有三段学院足球赛事：

1. 上学期：十一人制纺大杯
2. 上学期：八人制新生杯
3. 下学期：八人制纺大杯

网站先按年份索引，再按杯赛切换。目前已收录四项：`2025 · 十一人制纺大杯`、`2025 · 八人制新生杯`、`2026 · 八人制纺大杯`、`2026 · 十一人制纺大杯`。

## 发布到 GitHub Pages

改完 → 跑 [rule.md](rule.md) 第 14.2 节的四条命令 → 写更新通知 → 提交推送：

```powershell
git add data/team-records.json js/team-data.js data/player-stats.json
git add index.html css js assets docs
git commit -m "更新球队资料"
git push origin main
```

推送后 GitHub Actions 会自动校验并发布；约一两分钟后刷新线上页面即可看到更新。校验不通过时 Actions 会红叉，此时**不要**重复推送，先去 `Actions` 里看具体是哪一步失败。
