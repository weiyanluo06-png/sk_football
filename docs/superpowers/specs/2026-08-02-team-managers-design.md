# 球队经理板块设计说明

日期：2026-08-02
项目：生康足球队纪念站
状态：已确认，待用户复核

## 1. 目标

新增一个长期存在的“球队经理”板块，正式记录两位球队经理在球队中的身份与陪伴，同时与球员竞技数据体系保持清晰边界。

两位经理目前不区分具体分工，统一使用“球队经理”身份，不设置主次关系。

## 2. 页面位置

板块放在现有页面的：

1. 队员档案；
2. 球队经理；
3. 影像墙。

这个顺序从场上队员过渡到场边成员，再进入球队共同留下的影像。板块使用独立锚点，但暂不增加顶部导航入口，避免导航因两个人物变得拥挤。

## 3. 标题与文案

- 英文小标题：`TEAM MANAGERS`
- 主标题：`场边同行`
- 身份标签：`球队经理`
- 板块说明：`球场上的十一人之外，也有人陪球队走过每一次训练和比赛。`
- 统一职责说明：`协助球队日常事务、比赛记录、人员联络与赛场保障。`

文案强调球队归属和纪念价值，不把经理描述成通知人员或行政工具。

## 4. 人物卡片

两位经理使用完全相同的卡片尺寸、照片比例和信息层级，不设置“第一经理”“负责人”等未经确认的关系。

每张卡片展示：

- 真实照片；
- 姓名；
- 身份“球队经理”；
- 年级；
- 加入赛季；
- 统一职责说明；
- 一句个人介绍或与球队有关的话。

不展示：

- 球衣号码；
- 场上位置；
- 出场、进球、助攻、MVP、零封等比赛数据；
- 球员评分；
- 踢球风格；
- 战术板和阵容调换入口。

## 5. 视觉设计

板块延续现有校园足球纪念册风格，不使用粉色、花朵或刻意女性化的视觉符号。

- 主色继续使用球队绿色、纸白和深灰；
- 人物照片统一使用 `4:5` 竖版比例；
- 两张卡片等宽、等高；
- 圆角不超过 `8px`；
- 英文身份、加入赛季和辅助信息使用紧凑的小号字；
- 姓名是卡片内最主要的信息；
- 职责以简洁标签或短句呈现，避免堆叠过多胶囊标签；
- 可以使用低对比度的 `TEAM STAFF` 背景字作为版式元素，但不能影响人物可读性。

### 5.1 桌面端

- 两张人物卡并排组成一整行；
- 人物照片与文字信息采用一致布局；
- 卡片之间保留明确但克制的间距；
- 不使用自动轮播，两个人都应直接可见。

### 5.2 手机端

- 两张卡片保持相同宽度；
- 使用单行横向滚动和滚动吸附，一次重点展示一人；
- 保留下一张卡片的一小部分作为可滑动提示；
- 支持手指左右滑动，不开启自动滚动；
- 横向操作不能阻止页面正常上下滚动。

## 6. 数据来源

在 `data/生康足球队数据源.xlsx` 中新增独立工作表：

`球队经理`

建议字段：

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| 排序 | 是 | 控制展示顺序 |
| 姓名 | 是 | 经理姓名 |
| 年级 | 否 | 如 `2026级` |
| 加入赛季 | 否 | 如 `2026-2027` |
| 身份 | 是 | 统一填写 `球队经理` |
| 职责 | 否 | 暂时使用统一职责说明 |
| 个人介绍 | 否 | 一句话，建议不超过 36 个汉字 |
| 照片文件名 | 否 | 如 `manager-zhang.webp` |
| 照片焦点 | 否 | 如 `50% 30%` |
| 展示状态 | 是 | `展示` 或 `隐藏` |

照片缺失时显示球队盾牌、姓名和“照片待更新”，不能使用网络人物照片代替。

## 7. 数据边界

经理数据生成独立文件：

`js/manager-data.js`

该文件只提供球队经理板块所需信息，不能写入现有球员数组。

必须保证：

- 不改变正式球员数量；
- 不进入首发阵容和阵容候选池；
- 不参与球员评分和赛事统计；
- 不进入“全队档案”随机三人展示；
- 不进入新生展示；
- 经理资料缺失或文件加载失败时，板块仍保留稳定的空状态。

## 8. 空状态

当工作表中没有启用记录时，板块仍存在，但只显示一条克制的占位信息：

`球队经理资料待更新`

不生成虚构姓名、照片、年级、职责或个人介绍。

## 9. 后续扩展

如果以后增加教练、领队、摄影或其他工作人员，可以把板块标题扩展为“球队工作人员”，数据文件和工作表继续复用，并通过“身份”字段区分角色。

本次实现只展示两位球队经理，不提前制作工作人员分类、筛选器或复杂切换功能。

## 10. 预计文件改动

- `index.html`：在队员档案和影像墙之间增加球队经理板块，并引用经理数据文件；
- `css/style.css`：增加双人卡片、手机横滑和空状态样式；
- `js/main.js`：增加经理卡片渲染；
- `js/manager-data.js`：保存同步生成的经理数据；
- `tools/sync_team_workbook.py`：读取“球队经理”工作表；
- `data/生康足球队数据源.xlsx`：新增“球队经理”工作表；
- `tests/`：补充数据隔离、空状态和页面结构测试；
- `assets/managers/`：保存经过网页优化的经理照片。

## 11. 验收标准

- 两位经理在队员档案之后、影像墙之前直接可见；
- 两张卡片在桌面端尺寸一致并排展示；
- 手机端可以平滑横向切换，页面上下滚动不受影响；
- 修改 Excel 后运行同步流程能够更新经理姓名、照片和介绍；
- 经理不会出现在球员档案、战术板、阵容调换、评分和比赛统计中；
- 缺少照片或个人介绍时不会产生虚构内容；
- 新板块的配色、字体、间距、卡片圆角与现有网站保持一致。
