# 材料学院足球队入口设计

## 目标

在首页首屏的行动按钮组中增加材料学院足球队网站入口，让访问者能从生康足球队纪念站直接前往兄弟学院球队网站。

## 展示方式

- 入口放在“加入新生群”和“打开影像墙”之后，位于用户标注的首屏区域。
- 使用现有 `hero__cta` 胶囊按钮样式，保持三枚按钮的高度、圆角、描边和悬停反馈统一。
- 按钮文案为“材料足球队”，搭配外部链接图标，明确其跳转属性。
- 目标地址为 `https://weiyanluo06-png.github.io/wtu-football/`。

## 交互与安全

- 链接在新标签页打开，保留当前纪念站浏览进度。
- 使用 `target="_blank"` 与 `rel="noopener noreferrer"`，避免新页面访问原页面上下文。
- 提供明确的无障碍标签，说明链接将打开材料学院足球队网站。

## 响应式规则

- 桌面端三枚按钮保持横向排列。
- 手机端继续横向排列，通过缩小按钮内边距、字号和间距避免溢出。
- 最窄屏幕允许按钮组自然换行，不能遮挡首页统计、轮播控件或照片主体。

## 验证

- 自动检查首页包含目标链接、外链安全属性和按钮文案。
- 桌面与手机视口检查按钮无重叠、无截断，并确认目标链接可打开。
